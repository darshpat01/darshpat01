### 🚀 What I've built

**🤖 AI agent for an enterprise product**
Built my team's first working AI-agent integration: an **MCP (Model Context Protocol) server** in Spring AI that lets an LLM search, create, update and run data-integration jobs from plain-language requests.

**🔗 Data lineage with OpenLineage**
Built the component that records where data comes from and how it changes in each job, using the open **OpenLineage** standard. It sends events over RabbitMQ and is designed so it can never slow down or break a running job.

**👁️ Blind Vision: AI wearable for visually impaired people** · *Capstone project*
A cap-mounted camera and Raspberry Pi 4 that detect obstacles in real time and speak alerts.
Custom dataset of 6,011 images · YOLOv7 + ResNet · **94.8% mAP** · processing time cut from ~20 s to ~1 s per frame.

**🏆 [Financify](https://github.com/darshpat01/FINANCIFY): personal finance tracker** · *Top 50 of 4,300+ teams, Zeta-Hacks 3.0*
Track spending, subscriptions and goals; add a purchase by photographing the bill (OCR). I built the backend.
